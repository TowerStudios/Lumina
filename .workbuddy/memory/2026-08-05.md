# 2026-08-05 工作日志

## 修复：UI 不显示（AppLayout hooks 规则违规）

### 症状
- 应用启动成功但 UI 空白，日志报：
  - `Rendered more hooks than during the previous render`
  - `React has detected a change in the order of Hooks`
  - 错误发生在 `<AppLayout>` 组件

### 根因（重要教训）
- 上轮把设置弹窗的 `settingsOpen/setSettingsOpen` 两个 useUIStore hooks 加在了 `renderContent()` 函数**之后**。
- 而 AppLayout 在 renderContent 之前有两个**提前 return**（`onboardingChecking` 加载中、`!onboardingDone` 显示引导页）。
- 首次渲染：onboardingChecking=true → 提前 return（React 记录 0 个 hooks）
- 二次渲染：onboardingChecking=false → 继续执行 → 调用 2 个新 hooks
- React 检测到 hooks 数量不一致 → 整个组件树崩溃。

### 规则
**React Hooks 必须在组件顶层调用，且必须在任何提前 return 之前。**
在组件中间（尤其是有条件 return 之后）新增 hooks 是高风险操作。
修改此类组件时：检查所有提前 return 之前的所有 hooks 是否完整。

### 修复
- 把 settingsOpen/setSettingsOpen 移到组件顶部（useWindowSizeSync 之后、所有状态之前）。
- 删除 renderContent 后重复的 hooks。
- tsc 0 错误，已推送 8d4cb1f。
